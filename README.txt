# 🐉 Masmorra do Dragão

Um RPG de texto desenvolvido em Python como projeto de aprendizado de programação.

## 🎮 Sobre o projeto

Masmorra do Dragão é um jogo de aventura em que o jogador cria seu herói, escolhe uma classe e enfrenta inimigos em uma masmorra.

O projeto está em desenvolvimento e será expandido com novas ideias, mecânicas e histórias.

## ⚔️ Funcionalidades atuais

- Escolha entre Arqueiro, Guerreiro e Mago.
- Atributos de vida e ataque específicos para cada classe.
- Sistema de combate por turnos.
- Poções para recuperar vida.
- Ataques aleatórios e dano crítico.
- Chance de fugir das batalhas.
- Sistema de derrota e tentativa novamente.
- Narrativa com diálogos e pausas.

## 🛠️ Tecnologias

- Python
- Módulos `random` e `time`

## ▶️ Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra um terminal na pasta do projeto.
4. Execute:

```bash
python masmorra.py
```

## 📚 Objetivo

Praticar lógica de programação, estruturas condicionais, laços de repetição, variáveis e números aleatórios enquanto desenvolvo meu primeiro RPG de texto.

## 🚧 Status

**Em desenvolvimento.** Novas mecânicas, inimigos e elementos da história serão adicionados conforme o projeto evoluir.
